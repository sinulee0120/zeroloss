ZeroLoss 설치 및 사용 안내

버전 20261016.0026 · 인터넷 없이 이 키트만으로 설치됩니다. 처음부터 순서대로 따라 하세요.

  3. 풀 위치를 C:\로 바꾸고 [압축 풀기]를 누릅니다. (바탕화면이나 깊은 폴더에 풀면 경로가 길어 실행이 안 될 수 있습니다)
  4. ✔ 이렇게 되면 성공: C:\ZeroLoss-Kit-20261016.0026\ 폴더가 생기고 안에 아래 항목이 있습니다.

USB 메모리로 옮기기

2. 선 연결 (설치용)

설치할 때는 세 PC를 모두 공유기 LAN 포트(보통 1~4번, 노란색)에 꽂습니다. 공유기의 WAN 포트(인터넷 포트, 보통 파란색)는 아직 비워 둡니다.

[Windows PC] ──랜선──┐ [송신 PC] ──랜선──┼── 공유기 LAN 포트 1~4 [수신 PC] ──랜선──┘ 공유기 WAN 포트: 비워 둠 (6단계에서 송신 PC를 꽂음)

공유기 전원을 켜고 1분 기다립니다. PC들이 공유기에서 주소를 자동으로 받습니다.

3. 리눅스 PC 준비 (송신 PC, 수신 PC 각각 한 번씩)

  1. Ubuntu에 로그인하고 USB 메모리를 꽂습니다.
  2. 파일 앱에서 USB를 열고 2_Linux_PC_USB 폴더를 왼쪽의 홈으로 끌어다 놓아 복사합니다.
  3. 키보드에서 Ctrl+Alt+T를 눌러 터미널(검은 창)을 엽니다.
  4. 아래 두 줄을 한 줄씩 입력하고 Enter를 누릅니다. 
    cd ~/2_Linux_PC_USB
sudo bash zeroloss-linux-setup.sh
  5. 비밀번호를 물으면 로그인 비밀번호를 입력하고 Enter. 입력해도 화면에 아무것도 안 보이는 것이 정상입니다.
  6. 몇 분 기다립니다. 인터넷은 필요 없습니다.
  7. ✔ 이렇게 되면 성공: 마지막에 "완료!"와 함께 IP 주소와 아이디가 나옵니다. 종이에 적어 둡니다. (송신 PC 것, 수신 PC 것 따로)

✖ 안 되면: "설치되지 않은 것"이 나오면 화면을 사진으로 찍어 보내 주세요.

4. Windows PC에서 ZeroLoss 켜기

  1. C:\ZeroLoss-Kit-20261016.0026\1_Windows_PC\ZeroLoss\ZeroLoss.exe를 두 번 누릅니다.
  2. 파란 창 "Windows의 PC 보호"가 뜨면 [추가 정보] → [실행]을 누릅니다.
  3. "Windows 보안 경고(방화벽)" 창이 뜨면 체크 칸을 모두 켜고 [액세스 허용]을 누릅니다.
  4. ✔ 이렇게 되면 성공: ZeroLoss 창이 열립니다. Devices 칸은 아직 비어 있어도 됩니다.

편하게 쓰려면 ZeroLoss.exe를 오른쪽 버튼 → [바탕 화면에 바로 가기 만들기] 하세요(Windows 11은 [더 많은 옵션 표시] 안에 있음).

5. 리눅스 PC 등록 (송신 PC 한 번, 수신 PC 한 번)

  1. C:\ZeroLoss-Kit-20261016.0026\2_리눅스PC_등록.bat를 두 번 누릅니다. 검은 창이 열립니다.
  2. 물어보는 대로 입력하고 매번 Enter:
    • IP 주소: 3단계에서 적은 그 PC의 주소
    • 아이디: 그 PC의 로그인 아이디
    • 이름: 송신 PC면 sender, 수신 PC면 receiver
    • 자동 로그인: 수신 PC면 y (재부팅해도 영상 재생 화면이 뜨도록), 송신 PC면 n
  3. 그 PC의 비밀번호를 입력합니다. 화면에 안 보이는 것이 정상입니다.
  4. 1~3분 기다립니다.
  5. ✔ 이렇게 되면 성공: "완료!"가 나오고, ZeroLoss 창 Devices에 그 이름이 ✔와 함께 보입니다.
  6. 다른 PC도 같은 방법으로 한 번 더 합니다.

✖ 안 되면: 영어 메시지를 사진으로 찍어 보내 주세요. 자주 있는 경우: IP를 잘못 입력함, 3단계를 안 함, 비밀번호 틀림.

5-1. 샘플 영상 넣기 (송신 PC에서 한 번)

키트에는 시험용 영상 sample_1이 들어 있습니다: 원본(sample_1_original.mp4)과, 그 원본으로 미리 만들어 둔 UHD 시험 영상(sample_1_cache). 미리 만든 것이 있어서 시험이 바로 시작됩니다. 새로 만들면 몇 시간 걸립니다.

  1. 송신 PC에서 3단계처럼 Ctrl+Alt+T로 터미널을 엽니다(3단계에서 홈에 복사한 2_Linux_PC_USB 폴더를 씁니다).
  2. 아래 두 줄을 한 줄씩 입력하고 Enter: 
    cd ~/2_Linux_PC_USB
sudo bash zeroloss-sample-video.sh
  3. 비밀번호를 입력합니다(화면에 안 보이는 것이 정상). 3~6분 기다립니다.
  4. ✔ 이렇게 되면 성공: "완료!"가 나옵니다. ZeroLoss 창의 Source video 목록에 sample_1_original.mp4 · ✔ ready, starts at once가 보입니다(7단계).

✖ "ZeroLoss가 아직 이 PC에 없습니다"가 나오면: 5단계(등록)를 먼저 하세요.

6. 송신 PC 선 옮기기

  1. 송신 PC의 랜선을 공유기 LAN 포트에서 빼서 WAN 포트(인터넷 포트)에 꽂습니다.
  2. 1~2분 기다립니다. 송신 PC가 인터넷 회사처럼 공유기에 주소를 자동으로 줍니다. 공유기 설정은 건드리지 않습니다.
  3. ✔ 이렇게 되면 성공: ZeroLoss Devices에 ✔ sender · router WAN side, ✔ receiver · router LAN side가 보입니다.
[송신 PC] ──랜선── 공유기 WAN 포트 [Windows PC] ──랜선── 공유기 LAN 포트 [수신 PC] ──랜선── 공유기 LAN 포트 (무선 시험이면 랜선 대신 공유기 Wi-Fi)

무선(Wi-Fi) 시험을 할 때

  1. 수신 PC 화면 오른쪽 위를 눌러 Wi-Fi에서 시험할 공유기 이름을 고르고 Wi-Fi 비밀번호를 넣어 연결합니다.
  2. 수신 PC의 랜선은 꽂아 두어도 됩니다(조작용). 시험은 Wi-Fi로 받습니다.

7. 시험 시작

  1. 왼쪽 Test에서 고릅니다: Test type = PC receiver test, Video quality = UHD(또는 HD), Duration = 시험 시간(예: 10m, 1h, 100h).
  2. Source video의 CH1에서 sample_1_original.mp4 · ✔ ready, starts at once를 고릅니다(5-1단계를 했을 때).
    • ✔ ready, starts at once: 미리 만든 영상이 있어 바로 시작합니다.
    • made first (takes a while): 먼저 만들어야 합니다(UHD는 몇 시간). 고르는 순간 만들기 시작하고, 아래에 진행률이 보입니다.
    • 미리 만든 것은 CH1 · UHD · 기본 비트레이트(35 Mbps) · 10분짜리 하나입니다. HD, 다른 채널, 영화 전체(Advanced의 길이 설정)는 처음 한 번 만들어야 합니다. 한 번 만든 것은 다시 만들지 않습니다.
  3. 오른쪽 Devices 줄을 확인합니다:
    • sender 줄: Sender
    • receiver 줄: Receiver, CH1, Wired(유선) 또는 Wireless(무선)
  4. 장비 이름 앞이 ○(응답 없음)이면, 그 줄의 IP 상자 ▼를 눌러 다른 주소를 고르거나 직접 입력하고 Enter.
  5. [Start]를 누릅니다. 처음 1~2분은 점검합니다. 처음 시험할 때는 시험 영상을 만드느라 더 걸릴 수 있습니다.
  6. ✔ 이렇게 되면 성공: 아래 Status에 "Running normally", 수신 줄에 Playing · Jitter · Loss 0이 보입니다.

시험 중에는 PC들을 끄거나 선을 빼지 마세요. 시험이 끝나면 PC들은 원래 상태로 돌아갑니다.

9-1. 자동으로 안 될 때 손으로 하기

ZeroLoss가 자동으로 하는 일이 안 되면, 먼저 화면의 버튼을 쓰고, 그래도 안 되면 오른쪽 칸처럼 손으로 합니다. 어느 경우든 시험은 다시 [Start]할 수 있습니다.

보이는 것먼저 (버튼)손으로
송신 PC가 ○ (Cannot reach) — 이 PC에서 10.0.0.x로 가는 길이 없음Action Required의 [Add the route] → Windows가 물으면 [예]관리자 명령 프롬프트에서 route add 10.0.0.0 mask 255.255.255.0 192.168.45.1 (끝의 주소 = 이 PC 랜카드의 공유기 주소). 재부팅하면 다시 해야 합니다
"… has build …" (PC마다 버전이 다름)[Update PCs]그 PC로 키트의 packages 폴더 .deb 파일을 옮겨, 그 폴더의 터미널에서 sudo apt install ./zeroloss-agent_*.deb
랜카드 속도가 원래대로 안 돌아옴 (Action Required "Put a card setting back by hand")손으로 고친 뒤 [Fixed, check again] (그냥 계속하려면 [Continue anyway])Windows: 장치 관리자 → 네트워크 어댑터 → 그 카드 → 고급 → 속도 및 이중 = 자동 협상. 리눅스: sudo ethtool -s 카드이름 autoneg on. 또는 그 랜선을 뽑았다 다시 꽂기
Wi-Fi가 원래 망으로 안 돌아옴 (같은 창)손으로 고친 뒤 [Fixed, check again]그 PC 화면 오른쪽 위 Wi-Fi 메뉴에서 원래 망을 고르기 (또는 nmcli connection up id 원래망이름)
이 PC 랜카드 속도 케이스가 회색 "administrator approval was declined"다음 시험 때 Windows가 "변경을 허용할까요?"라고 물으면 [예]회색 케이스만 빠지고 나머지는 정상입니다
"Could not hold this PC's time sync" (SYS-012, 경고)그대로 진행해도 됩니다 (판정은 시계 보정을 빼고 함)그 리눅스 PC에서 시험 전 sudo timedatectl set-ntp false, 끝나고 sudo timedatectl set-ntp true
"The sender PC has Wi-Fi on …" 팝업 (NET-025)원하면 송신 PC의 Wi-Fi를 끄고 [Done] — ZeroLoss는 끄지 않습니다송신 PC 화면 오른쪽 위 메뉴 → Wi-Fi 끄기. 시험이 끝나면 다시 켜기
무선 밴드 목록이 비거나 "Scan failed"줄 밑에 적힌 이유대로 (예: older ZeroLoss → [Update PCs]) 한 뒤 [Scan]SSID를 몰라도 됨: 그 PC를 시험할 Wi-Fi에 손으로 붙이면 그 망으로 잽니다
송신 PC가 늦게 보냄 (보라 "sender trouble", SND-025)시험 중에는 송신 PC에서 다른 무거운 일(영상 변환, 업데이트, 큰 복사)을 하지 않기송신 PC가 뜨거우면(90 °C 넘음) 운영체제가 CPU를 잠깐씩 쉬게 해 송신이 멈춥니다 — 통풍, 덮개 열기. 쓰지 않는 Wi-Fi는 끄는 것을 권합니다(팝업 안내)
모든 PC 설정을 원래대로 돌리고 싶음시험이 끝난 뒤 [Reset All] (시험 중엔 회색: 먼저 Stop)응답 없는 PC는 그 PC를 다시 켠 뒤 [Reset All]
ZeroLoss 창이 멈춘 것 같음창을 닫고 다시 열기 — 시험은 계속 돕니다그래도 이상하면 [Reset All]

11. 지우는 방법

  • Ubuntu PC: 터미널에서 sudo apt purge zeroloss-agent (ZeroLoss가 바꾼 설정도 원래대로 돌아갑니다)
  • Windows PC: ZeroLoss 창을 닫고 C:\ZeroLoss-Kit-20261016.0026과 C:\ProgramData\ZeroLoss 폴더를 지웁니다. 보고서가 필요 없으면 C:\ZeroLoss도 지웁니다.
