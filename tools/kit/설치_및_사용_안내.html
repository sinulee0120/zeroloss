ZeroLoss 설치 및 사용 안내

버전 {BUILD} · 인터넷 없이 이 키트만으로 설치됩니다. 처음부터 순서대로 따라 하세요. ZeroLoss 창 오른쪽 위 [?]를 누르면 이 안내서가 지금 고른 시험의 부분에서 열립니다.

이 프로그램이 하는 일:
  • IPTV test: 공유기를 통해 IPTV 영상(UHD 35 Mbps 등)을 PC와 태블릿(최대 3대)으로 보내고, 패킷이 빠지는지(Loss)·흔들리는지(Jitter)를 5분 단위로 기록하고 보고서를 만듭니다.
  • Throughput(속도 시험): 공유기의 유선·무선 속도를 PC와 태블릿마다, 설정(속도·폭·모드)마다 보내기(TX)·받기(RX) 둘 다 잽니다.

1. 키트 압축 풀기

Windows PC

  1. 받은 파일 ZeroLoss-Kit-{BUILD}.zip을 C:\ (C 드라이브 맨 위)에 복사합니다.
  2. 파일을 마우스 오른쪽 버튼으로 누르고 [모두 압축 풀기...]를 누릅니다.
  3. 풀 위치를 C:\로 바꾸고 [압축 풀기]를 누릅니다. (바탕화면이나 깊은 폴더에 풀면 경로가 길어 실행이 안 될 수 있습니다)
  4. ✔ 이렇게 되면 성공: C:\ZeroLoss-Kit-{BUILD}\ 폴더가 생기고 안에 아래 항목이 있습니다.
폴더/파일무엇
설치_및_사용_안내.html지금 보는 안내서
1_Windows_PC\ZeroLoss-Controller-Setup-{BUILD}.exeWindows PC 설치 파일 (리눅스 PC·태블릿에 넣을 프로그램도 들어 있음)
2_Linux_PC_USB\Ubuntu PC 두 대에 옮길 폴더 (필요한 프로그램과 샘플 영상)

USB 메모리로 옮기기

  1. C:\ZeroLoss-Kit-{BUILD}\2_Linux_PC_USB 폴더를 통째로 USB 메모리에 복사합니다.

2. 선 연결 (설치용)

설치할 때는 세 PC를 모두 공유기 LAN 포트(보통 1~4번, 노란색)에 꽂습니다. 공유기의 WAN 포트(인터넷 포트, 보통 파란색)는 아직 비워 둡니다.

[Windows PC] ──랜선──┐ [송신 PC] ──랜선──┼── 공유기 LAN 포트 1~4 [수신 PC] ──랜선──┘ 공유기 WAN 포트: 비워 둠 (6단계에서 송신 PC를 꽂음)

공유기 전원을 켜고 1분 기다립니다. PC들이 공유기에서 주소를 자동으로 받습니다.

3. 리눅스 PC 준비 (송신 PC, 수신 PC 각각 한 번씩)

  1. Ubuntu에 로그인하고 USB 메모리를 꽂습니다.
  2. 파일 앱에서 USB를 열고 2_Linux_PC_USB 폴더를 왼쪽의 홈으로 끌어다 놓아 복사합니다.
  3. 키보드에서 Ctrl+Alt+T를 눌러 터미널(검은 창)을 엽니다.
  4. 아래 두 줄을 한 줄씩 입력하고 Enter를 누릅니다. 
    cd ~/2_Linux_PC_USB
sudo bash zeroloss-linux-setup.sh
  5. 비밀번호를 물으면 로그인 비밀번호를 입력하고 Enter. 입력해도 화면에 아무것도 안 보이는 것이 정상입니다.
  6. 몇 분 기다립니다. 인터넷은 필요 없습니다.
  7. ✔ 이렇게 되면 성공: 마지막에 "완료!"와 함께 IP 주소와 아이디가 나옵니다. 종이에 적어 둡니다. (송신 PC 것, 수신 PC 것 따로)

✖ 안 되면: "설치되지 않은 것"이 나오면 화면을 사진으로 찍어 보내 주세요.

4. Windows PC에 ZeroLoss 설치

  1. C:\ZeroLoss-Kit-{BUILD}\1_Windows_PC\ZeroLoss-Controller-Setup-{BUILD}.exe를 두 번 누릅니다.
  2. 파란 창 "Windows의 PC 보호"가 뜨면 [추가 정보] → [실행]을 누릅니다.
  3. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"가 뜨면 [예]. 묻는 것 없이 설치가 끝납니다(1분 정도).
  4. 마지막 창에서 [ZeroLoss 켜기]가 체크된 채로 [마침]을 누릅니다.
  5. ✔ 이렇게 되면 성공: ZeroLoss 창이 열립니다. Devices 칸은 아직 비어 있어도 됩니다. 바탕 화면과 시작 메뉴에 ZeroLoss Controller가 생깁니다.

시작 메뉴에는 ZeroLoss 사용 안내(이 안내서)와 ZeroLoss 리눅스 PC 등록도 생깁니다.

✖ "시험이 진행 중입니다"가 나오면: 이 PC에서 시험이 돌고 있습니다. 시험이 끝난 뒤 다시 설치하세요. 시험은 끊기지 않습니다.

5. 리눅스 PC 등록 (송신 PC 한 번, 수신 PC 한 번)

  1. ZeroLoss 창 Devices 아래의 [Add a Linux PC]를 누릅니다.
  2. 칸을 채웁니다:
    • IP address: 3단계에서 적은 그 PC의 주소
    • User name: 그 PC의 로그인 아이디
    • Password: 그 PC의 비밀번호 (한 번만 쓰고 저장하지 않습니다)
    • Name: 송신 PC면 sender, 수신 PC면 receiver
    • Log this user in after a reboot: 수신 PC면 체크 (재부팅해도 영상 재생 화면이 뜨도록), 송신 PC면 비워 둠
  3. [Add a Linux PC]를 누르고 1~3분 기다립니다. 버튼에 "Installing on …"이 보입니다.
  4. ✔ 이렇게 되면 성공: "Linux PC added" 창이 뜨고, Devices에 그 이름이 ✔와 함께 보입니다.
  5. 다른 PC도 같은 방법으로 한 번 더 합니다.

같은 일을 시작 메뉴의 ZeroLoss 리눅스 PC 등록(검은 창에서 묻는 대로 입력)으로도 할 수 있습니다.

✖ 안 되면: 영어 메시지를 사진으로 찍어 보내 주세요. 자주 있는 경우: IP를 잘못 입력함, 3단계를 안 함, 비밀번호 틀림.

5-1. 샘플 영상 넣기 (송신 PC에서 한 번)

키트에는 시험용 영상 3개가 들어 있습니다: 미리 만들어 둔 UHD 10분 영상(35 Mbps), 채널마다 하나(sample_1_CH1_UHD.ts, sample_2_CH2_UHD.ts, sample_3_CH3_UHD.ts, 각각 설명 파일 .json과 함께). 이미 만든 영상이라 시험이 바로 시작됩니다. 새로 만들면 한 편에 몇 시간 걸립니다.

  1. 송신 PC에서 3단계처럼 Ctrl+Alt+T로 터미널을 엽니다(3단계에서 홈에 복사한 2_Linux_PC_USB 폴더를 씁니다).
  2. 아래 두 줄을 한 줄씩 입력하고 Enter: 
    cd ~/2_Linux_PC_USB
sudo bash zeroloss-sample-video.sh
  3. 비밀번호를 입력합니다(화면에 안 보이는 것이 정상). 한 편에 2~4분 걸립니다.
  4. ✔ 이렇게 되면 성공: "완료!"와 함께 영상마다 채널이 나옵니다. 7단계의 Source video 목록에서 CH1에 sample_1_CH1_UHD.ts, CH2에 sample_2_CH2_UHD.ts, CH3에 sample_3_CH3_UHD.ts를 고르면 ✔ ready, starts at once로 바로 시작합니다. 각 영상은 그 채널용이고 UHD 전용입니다. 다른 채널·HD·내 영화는 처음 한 번 만들어야 합니다.

✖ "ZeroLoss가 아직 이 PC에 없습니다"가 나오면: 5단계(등록)를 먼저 하세요.

5-2. 태블릿 연결 (태블릿으로 시험할 때)

  1. 태블릿에서 설정 → 휴대전화 정보(태블릿 정보) → 소프트웨어 정보의 빌드번호를 7번 누릅니다 ("개발자 모드를 켰습니다").
  2. 설정 → 개발자 옵션 → USB 디버깅을 켭니다.
  3. 태블릿을 USB 케이블로 수신 PC에 바로 꽂습니다. 태블릿에 "USB 디버깅을 허용하시겠습니까?"가 뜨면 [이 컴퓨터에서 항상 허용]을 체크하고 [허용].
  4. 태블릿을 시험할 공유기의 Wi-Fi에 연결합니다(태블릿 설정 → Wi-Fi). MAC 주소를 등록해야 하는 공유기(예: IPTV 전용 Wi-Fi)는 그 태블릿의 MAC을 공유기에 먼저 등록하세요. ZeroLoss가 연결에 실패하면 등록할 MAC을 화면에 알려 줍니다.
  5. ZeroLoss 창 Devices 위의 [Refresh]를 누릅니다.
  6. ✔ 이렇게 되면 성공: 수신 PC 아래에 tablet-1 줄이 생기고 배터리·Wi-Fi(신호·5 GHz·80 MHz 등)가 보입니다. "The ZeroLoss app is not on this tablet"이 보이거나 위에 [Update PCs to build …]가 보이면 누릅니다. 태블릿에 이 버전의 앱이 바로 설치됩니다.

시험 중에 태블릿을 바꾸거나 더 꽂았으면 [Refresh]를 누르세요. 뽑은 태블릿은 목록에서 빠집니다.

6. 송신 PC 선 옮기기

  1. 송신 PC의 랜선을 공유기 LAN 포트에서 빼서 WAN 포트(인터넷 포트)에 꽂습니다.
  2. 1~2분 기다립니다. 송신 PC가 인터넷 회사처럼 공유기에 주소를 자동으로 줍니다. 공유기 설정은 건드리지 않습니다.
  3. ✔ 이렇게 되면 성공: ZeroLoss Devices에 ✔ sender · router WAN side, ✔ receiver · router LAN side가 보입니다.
[송신 PC] ──랜선── 공유기 WAN 포트 [Windows PC] ──랜선── 공유기 LAN 포트 [수신 PC] ──랜선── 공유기 LAN 포트 (무선 시험이면 랜선 대신 공유기 Wi-Fi) [태블릿 1~3] ──USB── 수신 PC, Wi-Fi ── 공유기

PC로 무선(Wi-Fi) 시험을 할 때

  1. 수신 PC 화면 오른쪽 위를 눌러 Wi-Fi에서 시험할 공유기 이름을 고르고 Wi-Fi 비밀번호를 넣어 연결합니다.
  2. 수신 PC의 랜선은 꽂아 두어도 됩니다(조작용). 시험은 Wi-Fi로 받습니다.

7. IPTV 시험

  1. 왼쪽 Test에서 고릅니다: Test type = IPTV test, Video quality = UHD(또는 HD), Duration = 시험 시간(예: 10m, 1h, 100h).
  2. Source video의 채널마다 영상을 고릅니다(5-1단계를 했으면 CHn에 sample_n_CHn_UHD.ts · ✔ ready, starts at once).
    • ✔ ready, starts at once: 미리 만든 영상이 있어 바로 시작합니다.
    • made first (takes a while): 먼저 만들어야 합니다(UHD는 몇 시간). 고르는 순간 만들기 시작하고, 아래에 진행률이 보입니다. 한 번 만든 것은 다시 만들지 않습니다.
  3. 오른쪽 Devices 줄을 정합니다:
    • sender 줄: Sender
    • receiver 줄: Receiver, CH1, Wired(유선) 또는 Wireless(무선)
    • tablet 줄(있을 때): Receiver와 채널(CH1~3, 같은 채널도 됨). Wi-Fi: keep …는 지금 붙어 있는 Wi-Fi를 그대로 씁니다. 다른 Wi-Fi로 시험하려면 그 칸에서 고르세요([Scan]으로 다시 찾기). 안 쓰는 태블릿은 Not used.
  4. 장비 이름 앞이 ○(응답 없음)이면, 그 줄의 IP 상자 ▼를 눌러 다른 주소를 고르거나 직접 입력하고 Enter.
  5. [Start]를 누르면 "Start the test?" 창에 무엇을 시험하는지 나옵니다(채널마다 받는 장비·영화·태블릿 Wi-Fi). 맞으면 [Yes]. 처음 1~2분은 점검합니다.
  6. ✔ 이렇게 되면 성공: 아래 Status에 "Running normally", 수신 줄마다 Playing · Jitter · Loss 0이 보입니다. 태블릿 줄에는 Wi-Fi 신호(RSSI)·밴드·폭·11ax 등이 보입니다.

시험 중에는 PC들을 끄거나 선을 빼지 마세요. 창을 닫아도 시험은 계속 돕니다. 시험이 끝나면 PC들은 원래 상태로 돌아갑니다.

7-1. 속도 시험 (Throughput)

공유기를 지나는 속도를 잽니다. 6단계처럼 송신 PC가 WAN 포트에 꽂혀 있어야 합니다(WAN side PC). 나머지 PC는 LAN side PC로 잽니다.

Test type하는 일
Throughput · WiredLAN 쪽 PC의 유선 랜카드마다, 속도(10/100/1000 Mbps…)·이중 설정마다 TX/RX
Throughput · Wi-FiWi-Fi 카드와 태블릿마다, 밴드(2.4/5/6 GHz)마다, 폭(20/40/80/160 MHz)·모드(11ax/ac/n, a/b/g) 설정마다 TX/RX
Throughput · All위 둘 다
  1. Test type을 고릅니다. Devices의 PC마다 잴 카드에 체크합니다(Windows PC 자신도 this PC · measured as a LAN-side PC로 잴 수 있습니다).
  2. Wi-Fi 카드는 밴드마다 공유기의 Wi-Fi 이름을 고르고, 옆 칸에 비밀번호를 넣습니다(빈칸 = 암호 없음). 비밀번호는 이 PC에 암호화해 저장되고 다시 보이지 않습니다.
  3. 태블릿은 밴드마다 고른 Wi-Fi(암호 없는 Open)에 ZeroLoss가 붙였다가, 끝나면 원래 Wi-Fi로 돌려놓습니다.
  4. [Start]. 케이스마다 Live 화면에 TX/RX 그래프가 나오고, 다음 케이스로 넘어가면 다음 그래프가 나옵니다.
Windows PC 자신의 Wi-Fi(이 PC의 인터넷)를 재면 맨 마지막에 재고, 끝나면 원래 Wi-Fi로 돌아옵니다. 그동안 이 PC의 인터넷이 잠깐 끊깁니다. Windows가 "변경을 허용할까요?"라고 물으면 [예](랜카드·Wi-Fi 설정을 바꾸고 끝나면 되돌립니다).

카드가 지원하지 않는 설정은 회색 NOT RUN과 이유로 남고, 나머지는 그대로 잽니다.

8. 결과와 보고서 보기

5분마다 칸이 하나씩 생깁니다. 오래 시험하면 칸이 화면에 다 들어오도록 여러 칸이 한 칸(테두리)으로 합쳐 보입니다. Live view에서는 아직 판정 중인 5분 칸의 손실이 회색 밑줄로 보이고, 판정이 나면 빨강(공유기) 또는 파랑(송신·수신 쪽)으로 바뀝니다.

🟡 노랑빠진 것은 없지만 주의 (예: 흔들림이 기준보다 큼, 받는 쪽 재생 끊김). 도착 지연 변동은 유선 40 ms(DVB), Wi-Fi로 받는 장비는 100 ms를 넘을 때 노랑
🔴 빨강공유기 탓으로 패킷이 빠졌거나 흔들림이 너무 큼 → FAIL. 빨강은 공유기 문제일 때만 나옵니다
🔵 파랑(보라)문제가 있었지만 송신 PC나 받는 장비 쪽 원인 (공유기 탓 아님)
⚪ 회색자료 없음 (장비 끊김 등)
  • 칸에 마우스를 올리면 그 5분의 값과 이유가 나옵니다.
  • 정해진 시간이 지나면 저절로 끝납니다. 중간에 끝내려면 [Stop].
  • 끝나면 결과 창이 뜹니다: PASS(문제 없이 끝까지) / FAIL(빨강 있음) / INCOMPLETE(중간에 멈춤·자료 부족).
  • [Show report] 또는 위의 [Reports] 버튼으로 보고서를 엽니다. 손실이 난 순간의 화면 사진과 패킷 파일(pcap), 원인 분석 문장이 함께 들어 있습니다.
  • 보고서 맨 아래 Results table (for email): [Copy table]을 누르고 메일이나 문서에 붙여 넣으면 결과표가 선과 함께 그대로 들어갑니다.
  • 보고서 폴더: C:\ZeroLoss\Reports\R날짜-시간\ — report.html(브라우저로 열기), report.pdf. 이 폴더를 통째로 보내면 됩니다.

9-1. 자동으로 안 될 때 손으로 하기

ZeroLoss가 자동으로 하는 일이 안 되면, 먼저 화면의 버튼을 쓰고, 그래도 안 되면 오른쪽 칸처럼 손으로 합니다. 어느 경우든 시험은 다시 [Start]할 수 있습니다.

보이는 것먼저 (버튼)손으로
송신 PC가 ○ (Cannot reach) — 이 PC에서 10.0.0.x로 가는 길이 없음Action Required의 [Add the route] → Windows가 물으면 [예]관리자 명령 프롬프트에서 route add 10.0.0.0 mask 255.255.255.0 192.168.45.1 (끝의 주소 = 이 PC 랜카드의 공유기 주소). 재부팅하면 다시 해야 합니다
"… has build …" (PC마다 버전이 다름)[Update PCs]그 PC로 C:\Program Files\ZeroLoss\Controller\packages 폴더의 .deb 파일을 옮겨, 그 폴더의 터미널에서 sudo apt install ./zeroloss-agent_*.deb
랜카드 속도가 원래대로 안 돌아옴 (Action Required "Put a card setting back by hand")손으로 고친 뒤 [Fixed, check again] (그냥 계속하려면 [Continue anyway])Windows: 장치 관리자 → 네트워크 어댑터 → 그 카드 → 고급 → 속도 및 이중 = 자동 협상. 리눅스: sudo ethtool -s 카드이름 autoneg on. 또는 그 랜선을 뽑았다 다시 꽂기
Wi-Fi 설정(폭·모드)이 원래대로 안 돌아옴 (같은 창)손으로 고친 뒤 [Fixed, check again]Windows: 장치 관리자 → 네트워크 어댑터 → 그 Wi-Fi 카드 → 고급 → 채널 폭·무선 모드 = 원래 값(보통 자동). 리눅스: Wi-Fi를 껐다 켜기
Wi-Fi가 원래 망으로 안 돌아옴 (PC 또는 태블릿)손으로 고친 뒤 [Fixed, check again]PC: 화면 오른쪽 위 Wi-Fi 메뉴에서 원래 망을 고르기 (또는 nmcli connection up id 원래망이름). 태블릿: 설정 → Wi-Fi에서 원래 망을 고르기
이 PC 랜카드 속도 케이스가 회색 "administrator approval was declined"다음 시험 때 Windows가 "변경을 허용할까요?"라고 물으면 [예]회색 케이스만 빠지고 나머지는 정상입니다
"Could not hold this PC's time sync" (SYS-012, 경고)그대로 진행해도 됩니다 (판정은 시계 보정을 빼고 함)그 리눅스 PC에서 시험 전 sudo timedatectl set-ntp false, 끝나고 sudo timedatectl set-ntp true
"The sender PC has Wi-Fi on …" 팝업 (NET-025)원하면 송신 PC의 Wi-Fi를 끄고 [Done] — ZeroLoss는 끄지 않습니다송신 PC 화면 오른쪽 위 메뉴 → Wi-Fi 끄기. 시험이 끝나면 다시 켜기
무선 밴드 목록이 비거나 "Scan failed"줄 밑에 적힌 이유대로 (예: older ZeroLoss → [Update PCs]) 한 뒤 [Scan]SSID를 몰라도 됨: 그 PC를 시험할 Wi-Fi에 손으로 붙이면 그 망으로 잽니다
송신 PC가 늦게 보냄 (파랑 "sender trouble", SND-025)시험 중에는 송신 PC에서 다른 무거운 일(영상 변환, 업데이트, 큰 복사)을 하지 않기송신 PC가 뜨거우면(90 °C 넘음) 운영체제가 CPU를 잠깐씩 쉬게 해 송신이 멈춥니다 — 통풍, 덮개 열기. 쓰지 않는 Wi-Fi는 끄는 것을 권합니다(팝업 안내)
태블릿이 adb 목록에서 사라짐[Refresh]USB를 뽑았다 다시 꽂기. 수신 PC의 USB-C 도킹은 자주 끊기니 PC에 바로 꽂기
모든 PC 설정을 원래대로 돌리고 싶음시험이 끝난 뒤 [Reset All] (시험 중엔 회색: 먼저 Stop)응답 없는 PC는 그 PC를 다시 켠 뒤 [Reset All]
ZeroLoss 창이 멈춘 것 같음창을 닫고 다시 열기 — 시험은 계속 돕니다그래도 이상하면 [Reset All]

10. 새 버전으로 바꾸기

  1. 시험이 끝난 뒤, 새 키트의 ZeroLoss-Controller-Setup-새버전.exe를 실행합니다. 설정·보고서는 그대로 이어집니다.
  2. ZeroLoss 창에 [Update PCs to build …]가 보이면 누릅니다. 리눅스 PC와 태블릿 앱이 같은 버전으로 바뀝니다(몇 분).

12. 지우는 방법

  • 태블릿: ZeroLoss 창 Devices의 그 태블릿 줄 [✕](Remove) → [Yes]. 또는 태블릿 설정 → 애플리케이션 → ZeroLoss → 삭제. 개발자 옵션의 USB 디버깅도 끄고 싶으면 끕니다.
  • Ubuntu PC: 그 PC 줄의 [✕](Remove) → 아이디·비밀번호 입력 → [Remove]. 시험 자료까지 지우려면 "Also delete its test data"를 체크합니다. 또는 그 PC의 터미널에서 sudo apt purge zeroloss-agent (ZeroLoss가 바꾼 설정도 원래대로 돌아갑니다)
  • Windows PC: 설정 → 앱 → 설치된 앱 → ZeroLoss Controller → 제거. 마지막에 "시험 보고서와 설정도 지울까요?"를 묻습니다. [아니요](기본)를 누르면 보고서와 설정이 남습니다. 시험이 진행 중이면 제거하지 않습니다.
