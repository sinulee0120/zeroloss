# 새 컴퓨터에서 이어가기

> 이 저장소 하나에 지금까지의 기획·시안·규칙이 모두 들어 있다. 새 컴퓨터에서 받아서 Claude를 열면 그대로 이어진다.

## 1. 새 컴퓨터(Controller PC, Windows) 준비
1. Git, GitHub CLI(`gh`), Claude(데스크톱 앱 또는 Claude Code) 설치
2. `gh auth login` (브라우저 로그인, 계정 sinulee0120)
3. 저장소 받기: `gh repo clone sinulee0120/zeroloss`
4. Claude에서 `zeroloss` 폴더를 열기 → Claude가 `CLAUDE.md`를 자동으로 읽는다
5. Claude에게: "`docs/HANDOFF.md`를 읽고 이어서 진행해"

## 2. 이어지는 것 / 새로 해야 하는 것
| 항목 | 새 컴퓨터에서 |
|------|---------------|
| 기획서, 시안, 검증 플레이북, 도구 목록 | 저장소에 있음 → 그대로 이어짐 |
| Claude 계정, 커넥터(Exa, Context7) | 같은 계정으로 로그인하면 따라옴 |
| Claude 장기 기억(메모리) | 컴퓨터마다 따로 저장되고 **저장소에 넣지 않는다**(개인 메모가 들어 있을 수 있음, 공개 대비). 필요한 결정은 모두 `docs/`에 있으므로 새 PC에서는 CLAUDE.md·HANDOFF만으로 이어진다. 검증 플레이북은 `docs/playbook/` |
| 이전 대화 기록 | 따라오지 않음. 필요한 결정은 모두 문서에 적혀 있음 |
| 외부 도구 보관소 | 새로 구성 (`docs/15-tools.md`, P0 단계) |
