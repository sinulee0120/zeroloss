# 18. 참고 자료 목록 (무엇을 봤고, 툴 어디에 반영했나)

> 확인 수준: **✓ 원문** = 원문(PDF·RFC 본문·공식 문서)을 직접 읽음 / **◐ 본문 일부** = 공식 페이지·논문·검색 본문으로 해당 부분 확인 / **○ 요약** = 검색 요약·목차만.
> 원문은 저작권 때문에 저장소에 넣지 않는다. 수치는 원문(✓)에서 온 것만 판정·경고 기준 후보로 쓴다.
> 반영 위치 = 기획서 절(05·iptv 등) / 코드 / 시험. 코드·시험 연결은 `17-traceability.md`.

## 1-1. RFC 전수 재검토 (2026-09-25, 원문 기준)
