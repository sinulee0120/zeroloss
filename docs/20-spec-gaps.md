# 20. 기획서 결함·불일치 기록과 재발 방지 (2026-09-24 시작)

> 지금까지의 실수는 **기획서에 없거나(누락), 잘못 적혔거나(오류), 설명이 부족해 잘못 이해했거나(불명확), 문서끼리 서로 달랐거나(모순), 기획서를 보고도 코드가 따르지 않은(미준수)** 데서 나왔다. 코드와 기획서가 따로 놀면 기획서는 의미가 없다.
> 이 문서는 ① 발견한 결함을 모두 적고 ② 같은 종류가 다시 생기지 않게 하는 규칙을 둔다. 새 결함을 찾으면 **코드보다 먼저 여기와 해당 문서를 고친다.**
